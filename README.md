# Vinay Windows Website

A professional website for Vinay Windows - specializing in high-quality windows and doors manufacturing.

## Features

- Modern responsive design
- Product showcase for windows, doors, and facade systems
- Gallery section with project images
- Contact forms and career opportunities
- Interior design services

## Technology Stack

- PHP (Server-side)
- HTML5/CSS3
- JavaScript/jQuery
- Bootstrap framework
- MasterSlider for image galleries

## Setup

1. Ensure PHP is installed on your system
2. Start the development server: `php -S localhost:8000`
3. Open http://localhost:8000 in your browser

## Project Structure

- `index.php` - Homepage
- `about.php` - About page
- `products.php` - Products showcase
- `contact.php` - Contact page
- `common/` - Shared components (header, footer, menu)
- `css/` - Stylesheets
- `js/` - JavaScript files
- `images/` - Static assets and media

## Development

This is a traditional PHP website with server-side rendering. No build process required - changes are reflected immediately when you refresh the browser.
